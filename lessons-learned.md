# Lessons Learned from Practicing Nmap
# 1) Reconnaissance reveals a lot
One of the biggest lessons from practicing Nmap is how much information can be gathered from simple scanning. Open ports, running services, and operating system clues can quickly paint a picture of a target environment.

# 2) Different scan types serve different goals
I learned that not every scan is used for the same purpose. Some scans prioritize speed, some focus on stealth, and others gather deeper information about services and systems.

# 3) Service enumeration matters
Using version detection showed me how identifying software versions can help security professionals spot outdated services that may be vulnerable.

# 4) Responsible scanning is important
Practicing on safe targets like scanme.nmap.org taught me the importance of ethical and authorized security testing.

# My reflection
What stood out most to me is that ethical hacking starts with understanding before attacking. Reconnaissance is not just a technical step—it is strategic thinking.
